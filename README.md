# Програма днів народжень

Готовий статичний сайт для GitHub Pages.

## Файли

- `index.html` - головна сторінка.
- `styles.css` - оформлення.
- `app.js` - логіка пароля, календаря, збереження, нагадувань і генератора привітань.

## Як запустити

1. Відкрийте `index.html` у браузері.
2. Введіть унікальний пароль, наприклад `0503`.
3. Додавайте дні народження.

## Як працює пароль

Логіна більше немає. Пароль перетворюється на прихований код сховища. Якщо на іншому пристрої ввести той самий пароль, програма відкриє те саме сховище.

## Синхронізація між пристроями

GitHub Pages сам не має бази даних, тому для справжньої синхронізації потрібен Firebase.

У файлі `app.js` знайдіть:

```js
const FIREBASE_CONFIG = null;
```

Замініть `null` на налаштування вашого Firebase-проєкту:

```js
const FIREBASE_CONFIG = {
  apiKey: "ВАШ_API_KEY",
  authDomain: "ВАШ_ПРОЄКТ.firebaseapp.com",
  projectId: "ВАШ_PROJECT_ID",
  storageBucket: "ВАШ_ПРОЄКТ.appspot.com",
  messagingSenderId: "ВАШ_SENDER_ID",
  appId: "ВАШ_APP_ID"
};
```

Після цього записи будуть синхронізуватися через Firestore. Один і той самий пароль відкриватиме однакові дані на різних пристроях.

Для Firestore увімкніть базу даних і додайте правила на час особистого користування:

```txt
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /birthdayVaults/{vaultId} {
      allow read, write: if true;
    }
  }
}
```

Важливо: короткий пароль типу `0503` легко вгадати. Для приватних записів краще використати довший пароль.

## GitHub Pages

1. Створіть репозиторій на GitHub.
2. Завантажте файли в корінь репозиторію.
3. Увімкніть GitHub Pages у Settings -> Pages.
4. Оберіть гілку `main` і папку `/root`.

## ШІ-блок

ШІ-блок створює готовий промпт, відкриває ChatGPT і дає змогу завантажити просту листівку. Справжня генерація зображень прямо на сайті потребує захищеного серверного API.
