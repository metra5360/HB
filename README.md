# Програма днів народжень

Це готовий статичний сайт для GitHub Pages.

## Файли

- `index.html` - головна сторінка.
- `styles.css` - оформлення.
- `app.js` - логіка авторизації, збереження, календаря, нагадувань і генератора привітань.

## Як запустити

1. Відкрийте `index.html` у браузері.
2. Створіть акаунт.
3. Додайте дні народження.

## Як залити на GitHub Pages

1. Створіть репозиторій на GitHub.
2. Завантажте ці файли в корінь репозиторію.
3. Увімкніть GitHub Pages у Settings -> Pages.
4. Оберіть гілку `main` і папку `/root`.

## Важливо

Дані зберігаються в `localStorage` браузера. Це означає, що кожен користувач має свої записи на тому пристрої й у тому браузері, де він увійшов. Для синхронізації між різними пристроями потрібен сервер або база даних, наприклад Firebase або Supabase.

ШІ-блок створює готовий промпт, відкриває ChatGPT і дає змогу завантажити просту листівку. Справжня генерація зображення прямо на сайті потребує захищеного серверного API, щоб не показувати ключі доступу у відкритому коді GitHub.
